# Machine Shop Control Board

ระบบควบคุมเครื่องมือช่าง สต็อก และการตรวจก่อนกลับบ้านของ Machine Shop

## ไฟล์

- `index.html` — หน้าแอปทั้งหมดในไฟล์เดียว (HTML, CSS, JavaScript)

## ความสามารถ

- **สต็อก** — เครื่องมือช่างและอะไหล่เครื่องจักร พร้อม Safety stock, จุดสั่งซื้อ (ROP), จำนวนที่ควรสั่ง และ Cycle count
- **ตรวจก่อนกลับ** — บอร์ดเครื่องมือแบบ shadow board, เช็คสภาพเครื่องจักรทีละเครื่อง, ชั้นวัสดุ และพื้นที่
- **สรุป** — ของหายค้าง, ของที่หายบ่อย, ของที่ยืมนาน และเครื่องจักรที่ไม่ผ่านบ่อย ใน 30 วันล่าสุด
- **จัดการบอร์ด** — เพิ่ม แก้ไข ลบเครื่องมือ พร้อม Serial no. และแบรนด์/รุ่นเครื่องจักร
- **ประวัติ** — ผลตรวจย้อนหลัง แก้ไขหรือลบได้

## การใช้งาน

แอปนี้ใช้ฐานข้อมูลของ claude.ai Artifacts (`db` และ `user` capability) จึงต้องเปิดใช้งานผ่านลิงก์ claude.ai เท่านั้น
ถ้าเปิดไฟล์นี้โดยตรงหรือผ่าน GitHub Pages หน้าแอปจะแสดงได้ แต่จะเชื่อมต่อฐานข้อมูลไม่ได้ และบันทึกหรือดูข้อมูลไม่ได้

repo นี้ใช้เก็บสำเนาโค้ดและประวัติการแก้ไข
